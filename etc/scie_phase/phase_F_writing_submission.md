## §0. 이 Phase를 처음 보는 사람을 위한 배경

모든 재료가 준비된 상태에서 논문을 조립·검증·투고하는 Phase다. 타겟은
**SMPT**(Simulation Modelling Practice and Theory, Elsevier, IF ~4.0) — "현실 시스템의
데이터 기반 시뮬레이션 + 실무 해법"을 중시하는 SCIE 저널이며, 우리가 벤치마킹한 세종시
공공자전거 ABM 논문과 같은 성격이다.

이 Phase의 성패는 글솜씨보다 **정합성 관리**에 달려 있다: 본문에 인용되는 수십 개의
수치가 전부 결과 CSV와 일치해야 하고(레포 원칙 "코드가 진실" — 수기 수치 금지),
V&V 서사가 검증 리포트와 어긋나지 않아야 하며, 한계(전문가 인터뷰 부재·고객 포기
미모델링·단일 빌딩)를 리뷰어보다 먼저 논문이 말해야 한다.

**이 Phase의 필수 용어** (상세: research_plan_scie.md §0.7): SMPT / highlights(기여
3~5줄 요약, Elsevier 필수 제출물) / cover letter(편집자 소개 서한) / Data Availability
(데이터 출처·접근성 명시 절) / Zenodo DOI(재현 패키지의 영구 식별자).
