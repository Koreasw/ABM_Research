## §3. 로봇 FSM 거동 5항목 (K50_1)

FSM은 **8상태 + 직교 속성**(결정 4)이다. 화면에서 상태 전이가 **설계 순서대로** 일어나는지 본다.

| # | 항목 | 기대 |
|---|---|---|
| ⓖ | **정상 릴레이 1건 완주** | 로봇 1대를 눈으로 따라간다: `IDLE` → 카운터 이동 → (`WAIT_RIDER`) → `HANDOFF` 60초 → EV 승강장 이동 → `WAIT_EV`(up) → `RIDING`(up) → 사무실 이동 → `DROP` 30초 → EV 이동 → `WAIT_EV`(down) → `RIDING`(down) → 로봇존 복귀 → `IDLE` |
| ⓗ | **`WAIT_RIDER`가 실제로 발생한다** | 로봇이 카운터에 **먼저 도착해 라이더를 기다리는** 장면이 최소 1회 보인다. (A4 골든패스 케이스 ②가 측정하는 상태 — 화면에서 한 번도 안 보이면 배차가 너무 늦다는 신호) |

## §4. 신규 규약 4항목 (K200_1 — 포화·감쇠 구간)

**이 절이 H1 고유의 위험 지대다.** 결정 #26·#28·#27이 만든 거동을 육안으로 확인한다.

#### ⓛ 배터리 — **떨어지되 임계에 닿지 않는다**

- **기대**: 로봇 SOC가 run 내내 **단조 감소**하고 종료 시 **43~90%** 사이다.
  20% 임계는 **발화하지 않는다**. 유휴 로봇은 로봇존에서 **SOC가 오른다**(기회 충전).
- ⚠️ **20%에 안 닿는 것이 정상이다** — 결함이 아니라 결과다(결정 #26).
  임계가 발화하면 오히려 **소모율 배선을 의심**한다.
- **결함이면**: SOC가 100%에서 안 움직인다(소모 미배선) / 순식간에 0이 된다(단위 오류,
  Wh/s와 Wh/min 혼동) / 배달 중인데 오른다.

#### ⓜ 보행자 감쇠 — **드레인 구간에서 배경이 옅어진다**

- **기대**: 마지막 주문 + 7,200 s를 지나면 로비의 **새 보행자 등장 빈도가 눈에 띄게
  줄어** 평시(2.0/분) 수준으로 내려간다. 30분 램프 동안 점진적이다.
- **결함이면**: 끝까지 피크 밀도 그대로(감쇠 미적용) / 갑자기 0이 됨(램프 미적용 또는
  구 `ped_end` 컷오프 부활).

#### ⓝ 포화 — **로봇 큐가 쌓이는 것이 정상이다**

- **기대**: K200에서 **배차 대기 주문이 계속 쌓이고**, 주문 창(1시간)이 끝난 뒤에도
  로봇이 한참 더 배달한다. 마지막 배달이 마지막 주문보다 **훨씬 늦다**.
- ⚠️ **이것은 결함이 아니라 설계된 결과다** — baseline 5대의 ρ는 K200에서 **2.03**이다
  (점검 §11.3). 큐가 안 쌓이면 오히려 **배차 또는 사이클 배선을 의심**한다.
- **결함이면**: 큐가 전혀 안 쌓임 / run이 cap으로 끊김(`termination_reason == "cap"` —
  이 경우 `max_overrun_sec_robot`을 올려 재실행할 것, 게이트 FAIL이 아니다).

#### ⓞ 수직 경합 — **로봇이 공용 EV 앞에 줄을 서는가**

> 🔴 **2026-08-11(결정 #31) 항목 교체.** 구판은 "전용 EV가 한산해 보이는가"였다.
> 실측상 보행자 대기의 모드 간 차이는 ±1~6 s로 육안 판별 범위 밖이고 고부하에서
> 부호가 H1에 유리하다 — **관찰 가능한 수직 경합은 로봇 쪽에 있다.**

- **기대**: K200에서 **공용 EV3·EV4 승강장에 로봇 마커(◆ `deliver_up`/`return`)가
  머무는 시간**이 눈에 띈다. 사이드바 `로봇 탑승거부(정원)`가 0이 아니다.
- **결함이면**: 로봇이 EV 앞에서 **한 번도** 기다리지 않는다(대기 계측 배선 의심) 또는
  전용 EV1·EV2 승강장에 ◆가 보인다(**B3 위반** — 게이트가 먼저 잡아야 한다).
- ⚠️ **정성 관찰이며 논문 수치의 근거가 아니다.** 정량 판정은 로봇 EV 대기
  (`robot.ev_wait_up/down_*`)와 `board_denied`로 한다. 보행자 전용/공용 지표는
  **타당성 가드**이지 외부성의 증거가 아니다(결정 #31).
