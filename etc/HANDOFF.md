사용자 지시: "지하1층·지하2층을 새로 만든다. 로봇과 무관하고, 이용자가 EV로

> **§1.3과의 관계 주의**: 개정계획 §1.3의 "B1 전면 삭제"는 *로봇 충전용* B1을
> 지운 것이고, §1.6이 새로 만든 것은 *사람 전용* B1·B2다. **로봇은 여전히 지하에
> 내려가지 않고 1F 로비존에서 대기＝충전한다.** 두 절이 모순처럼 보이면 §1.6이 기준.

확정 사양(사용자 확정, 재론 금지):

| 항목 | 값 |
|---|---|
| 지하층 | B1(−1)·B2(−2), `building.n_basements: 2` |
| 용도 | 승하차 전용 — 사무실·복도 노드 **0개**, `floor_center` 1 + EV 정차 4 |
| EV 운행 | **4대 전부 B2~10F** (대칭 유지 → V2-BAL 게이트 무변경) |
| 보행자 지상측 종점 | **1F 0.50 / B1 0.30 / B2 0.20** (`pedestrian.ground_split`) |
| 보행자 총량 | **7.5명/분 유지 — 재분배**(상주 900명×0.5트립/h 캘리브레이션 보존) |
| 층고 | 4.0 m 동일 (B1 = −4 m, B2 = −8 m) |
| 라이더·로봇 | 지하 미사용 |

**반드시 알아야 할 구현 규약 — 층 rank**: 층 라벨에 0이 없어서 `|라벨 차|`가
물리적 층수와 어긋난다(1F↔B1은 라벨 차 2, 실제 1개층). 그래서
`space.floor_rank(f) = f if f>=1 else f+1`(B2=−1, B1=0, 1F=1)을 도입했고,
**거리·보간에는 반드시 rank를, 순서 비교에는 라벨을** 쓴다(rank가 라벨에 대해
순증가라 비교 결과는 같다). 적용 지점: `elevator._decide_next`(최근접 정차),
`elevator.step`(position_floor 보간), `control_system._estimate_wait`,
`model._evsel_on_register`, `elevator_physics.floor_height_between`.
**`position_floor`(KPI `ev{i}_floor`, 시각화 y)의 단위가 rank로 바뀌었다** —
지상층은 rank == 라벨이라 기존 값은 하나도 안 변한다.

관측된 효과(의도한 방향): K50_1 seed42 EV util **0.71~0.74 → 0.77~0.81**,
wall span 10611 → 10615 s. util이 **떨어지면** 지하 정차가 서비스되지 않는 것이니
rank 변환부터 의심할 것.
