# 2D 배달 수요 → 빌딩 층별 수요 매핑: 방법론 (v4)

> 대상 파이프라인: `analysis/load_data.py`(로더) · `analysis/scenario_loader.py`(리플레이) · `simulation/space.py`(빌딩 그래프) · 10F 빌딩(`configs/baseline_10f.yaml`, 사무층 2..10F)
> 작성: 2026-07-07. **본 문서는 독립 문서로, 이 문서만으로 2D→3D 매핑의 전 과정을 정의·재현할 수 있다.**

---

## 0. 목적과 범위

평면(2D) 배달 데이터의 각 주문 — *식당 위치 · 고객 위치 · 배달거리* — 를 특정 **층·호실에 배정된 건물 내부 수요**로 변환하고, 배달원의 이동거리를 **수평·수직·층내** 세 성분으로 분해한다.

본 방법론의 핵심 원칙은 **관측분포 계승(trace-driven)** 이다: 층별 수요 분포를 외부 가정(균등분포, 재실인구 프로파일 등)으로 부여하지 않고, **관측된 식당–고객 배달거리의 경험분포를 수직 차원에 계승**한다. 이는 시뮬레이션 입력 모델링에서 가정된 모수분포보다 관측 경험분포를 우선하라는 원칙(trace-driven / empirical-distribution input modeling)을 따른 것이다.

**일반성**: 층·호실 배정(Step 2–4)은 주문의 **배달거리 `d_i` 만을 입력**으로 하며 좌표계·지역과 무관하다. 따라서 데이터셋의 **모든 시나리오 파일에 동일하게 적용**된다. 건물 앵커 좌표는 수평 이동거리 산출(Step 6)에만 쓰이는 고정 파라미터로, 기준 지역 데이터에서 1회 추출한다(§5.1; 추출 절차 자체가 방법론의 일부이므로 다른 지역 데이터에도 동일 절차로 재적용 가능).

모든 산출물은 원본 주문식별자(ORD_ID)로 역추적 가능하게 보존한다.

## 1. 입력

- **주문 집합**: 주문마다 `{주문ID(ORD_ID), 식당 좌표, 고객 좌표, 배달거리(식당→고객)}`
  - 공식 스키마: `ORDERS[i] = [ORD_ID, ORD_TIME, SHOP_LAT, SHOP_LON, DLV_LAT, DLV_LON, COOK_TIME, VOL, DLV_DEADLINE]`
  - 배달거리: `d_i = DIST[i][K+i]` (2K×2K 거리행렬; 0..K−1 픽업노드, K..2K−1 드롭노드)
- **건물 사양**(`configs/baseline_10f.yaml`): 층수, 층고, 층당 호실 수, 층 내부 복도·호실 배치, 최하 사무층

### 1.1 원본 거리의 성질 (데이터 실측)

원본 `DIST[i][K+i]` 와 식당–고객 **대권거리(haversine)** 의 비(比)는 데이터셋 전반에서 **상수 c ≈ 1.402** 이다(K50·K100·K200·K1000 파일 실측, 주문별 표준편차 ≈ 4×10⁻⁴; 지역과 무관한 데이터 생성기 상수).

```
d_i = DIST[i][K+i] ≈ c · haversine(shop_i, customer_i),   c = 1.402
```

- 즉 `DIST` 는 실측 도로망 최단거리가 아니라 **대권거리에 고정 우회계수 c 를 곱한 합성거리**다. c 는 문헌의 실측 우회계수(circuity/detour factor) 범위 1.2–1.5(Ballou et al. 2002; Boscoe et al. 2012)에 부합한다.
- 이 사실은 층 배정용 거리(`d_i`)와 수평 이동거리(Step 6 ①)의 척도 규약을 **동일한 c 로 통일**하는 근거가 된다.

## 2. 공리 (방법론의 논리적 근거)

### A1 — 서수적 노력 등가 (ordinal effort correspondence)

라이더 관점에서 2D 배달노력(시간)은 배달거리에 단조증가하고(`t = d/v`), 건물 내 배달노력은 층수에 단조증가한다(엘리베이터 주행·정지 + 대기·혼잡; 혼잡 시 증폭). 즉 **배달거리와 층은 모두 "배달 노력의 단조 축"** 이며, 이것이 거리→층 단조 사상의 공리적 근거다.

> **정직성 조항 (기수적 등가는 성립하지 않음)**: 절대 시간 스케일은 일치하지 않는다. 엘리베이터 기구학(가속 1.0 m/s², 최고 2.5 m/s, 층고 4 m) 기준 층당 한계 주행시간은 비혼잡 시 ≈ 1.6 s/층이고, 혼잡·대기를 포함해도 수십 초/층 수준이다. 이는 밴드폭 500 m/층이 라이더 속도로 함의하는 ≈ 95 s/층과 1–2차수 차이가 난다. 따라서 본 매핑이 보존하는 것은 **시간의 크기가 아니라 노력 분포상의 상대적 위치(순위)** 다.

### A2 — 지지집합 아핀 보정 (affine support calibration)

관측된 배달거리 분포의 지지집합(support)을 사무층 인덱스 범위에 **아핀 사상**한다. 층당 거리 밴드폭은

```
w = range(d) / n_office_floors
```

로 유도한다. 기준 데이터 실측(§5.3)에서 파일별 478–735 m, 강건 백분위 기준 405–559 m 가 얻어지며, 본 방법론은 이 유도 범위의 중앙 대표값 **w = 500 m 를 고정 파라미터로 채택**한다. 이로써 층별 수요 분포는 **관측 거리분포의 형상(shape)을 그대로 계승**한다 — 목표 분포를 가정하는 방식(균등, 재실 가중)과의 본질적 차이다.

### A3 — 결정론 결합 (deterministic coupling)

주문→층 결합은 거리 순위를 보존하는 **결정론적** 사상으로 한다. 근거:
1. **추적성**: 모든 층 배정이 원본 ORD_ID·배달거리로 완전 역추적된다(시드 불요, 데이터만으로 결정).
2. **무비용성(실증)**: 기준 데이터에서 `d_i` 와 식당→앵커 거리가 사실상 독립이므로, 결정론 결합에도 층↔수평거리 상관이 0 근방(실측 Spearman ρ ≈ −0.03)이다. 즉 실세계의 결합구조(고객의 층 ⊥ 식당 선택)를 훼손하지 않으면서 추적성을 얻는다.

## 3. 절차 (Step by Step)

### Step 1 — 건물 앵커 고정 (1회)

기준 지역 데이터의 **모든 고객 좌표의 중심점(산술평균)** 에 건물을 한 번 고정한다.

```
building_coord = ( mean(DLV_LAT), mean(DLV_LON) ) = (37.497054, 127.037138)
```

- 이 좌표는 **수평 이동거리(Step 6 ①)의 물리적 기준점**으로만 쓰이며, **층 배정에는 관여하지 않는다**.
- 여러 수요 시나리오를 "같은 건물"에서 반복 관측하는 설정에 맞춰, 시나리오마다 재계산하지 않는다.
- 산술평균(centroid)은 제곱거리 합의 최소점이다. 총 이동거리 대표성을 중시하는 대안은 기하 중앙값(geometric median, Weber 점)이며, 앵커 선택 민감도는 Step 7에서 다룬다. 다른 지역 데이터에 적용할 때는 동일 절차(해당 지역 고객좌표 평균)로 앵커를 재추출한다.

### Step 2 — 원본 배달거리 추출

주문 *i* 의 배달거리 `d_i = DIST[i][K+i]` 를 추출한다. **이 값이 층 배정의 유일한 입력**이며, 좌표·지역·건물 위치와 무관하게 결정된다. 따라서 Step 2–4는 모든 시나리오 파일에 동일하게 적용된다.

### Step 3 — 층 배정 (고정 밴드폭 아핀 이산화)

`d_i` 를 밴드폭 **w = 500 m**(§5.3에서 유도된 고정값)로 사무층에 사상한다.

```
floor_i = clip( 2 + ⌊ d_i / w ⌋ , 2 , 10 )
```

| d_i 범위(m) | 층 | | d_i 범위(m) | 층 |
|---|---|---|---|---|
| [0, 500) | 2F | | [2500, 3000) | 7F |
| [500, 1000) | 3F | | [3000, 3500) | 8F |
| [1000, 1500) | 4F | | [3500, 4000) | 9F |
| [1500, 2000) | 5F | | **[4000, ∞)** | **10F (클립)** |
| [2000, 2500) | 6F | | | |

- **형식적 표현**: 이 규칙은 값-아핀 이산화(value-affine discretization)로, 역CDF 표기로는 `floor_i = F_floor⁻¹(F̂_d(d_i))` 에서 목표 층 질량 `p_f` 를 **데이터의 밴드별 경험 질량으로 추정**한 경우와 동치다. 즉 목표 분포를 가정하지 않고 관측분포에서 추정한다(trace-driven).
- 배달거리가 클수록 높은 층(약단조 증가, A1). 로비층(1F)은 제외.
- 특정 층에 수요가 없는 것(공실)을 인위적으로 막지 않는다(허용).
- 강건 변형: 극단 꼬리의 클립 편중이 우려되면 백분위 앵커 아핀 사상(p1→2F, p99→10F)을 대조 변형으로 쓴다(Step 7).

### Step 4 — 호실 배정

층 내부 위치는 배달 KPI에 미미하므로, 층 안에서 **균등 무작위**로 호실을 배정한다.

```
office_i ~ Uniform{ 0 … n_off−1 }     (n_off = 12)
```

- **RNG 명세(재현성 규약)**: 시나리오 파일마다 Python 표준 `random.Random(42)` 를 새로 초기화하고, 주문 행 순서(i = 0..K−1)대로 `randrange(12)` 를 1회씩 호출한다. 라이브러리·시드·호출 순서까지 고정해야 동일 결과가 보장된다.

### Step 5 — 수요 레코드 직렬화 (원본 추적)

주문마다 `{원본 ORD_ID, row_index, 배달거리 d_i, 배정 층, 배정 호실}` 을 저장한다.

- **ORD_ID를 키로** 모든 배정을 원본 주문으로 역추적할 수 있게 한다(`row_index` 는 DIST 노드 인덱스로 병기).
- 앵커 좌표·밴드폭 w·우회계수 c·시드/RNG 명세·방법론 버전을 **메타데이터로 함께 기록**해 재현성을 확보한다.

> 산출물 예: `data/floor_mapping/{시나리오}_floor_mapping.json`

### Step 6 — 이동거리 3분해

배정 결과 위에서, 배달원 총 이동거리를 물리적으로 독립된 세 성분으로 분해한다. 건물 내부(②③)는 `configs/baseline_10f.yaml` 로 구성한 **빌딩 배치 그래프**(`simulation/space.py`)의 실제 간선거리에서 산출한다.

| 성분 | 정의 | 산출 방식 |
|---|---|---|
| **① 수평** `horizontal_m` | 식당 → 건물 입구 | 식당–앵커 **대권거리 × 우회계수 c** |
| **② 수직** `vertical` | 1층 입구 → 배정 층 중앙 | `입구거리 + (층−1) × 층고` |
| **③ 층내** `in_floor_m` | 배정 층 중앙 → 호실 | 빌딩 그래프 최단 보행거리 |

```
horizontal_i     = c · haversine(shop_i, building_coord)      (c = 1.402)
vertical_total_i = entrance_m + (floor_i − 1) × floor_height_m
total_travel_i   = horizontal_i + vertical_total_i + in_floor_i
```

- **① 수평 규약 통일**: 층 배정용 `d_i` 가 이미 `c×대권거리`이므로(§1.1), 수평 성분에도 동일 c 를 적용해 두 거리척도의 규약을 일치시킨다. c 는 임의 가정이 아니라 **원본 데이터에서 실증 식별된 값**이다.
- **② 수직**: 입구 성분(1층 입구→중앙) + 층간 성분(층고 × 층수차). 층 중앙 도착 기준이라 ③과 연속적으로 이어진다.
- **③ 층내**: 층 중앙에서 복도를 따라 호실 분기까지의 실제 보행경로 거리. 본 건물 그래프에서는 `6 + |14 − office_position_m|` (중앙→중앙복도 3 m + 복도 이동 + 분기 3 m).

> 산출물 예: `data/floor_mapping/{시나리오}_movement_distances.json`

### Step 7 — 검증·민감도 프로토콜

| 항목 | 내용 | 기준/실측 예 |
|---|---|---|
| **층 분포** | 층별 배정 건수·공실층 기록 | 예: K50_1 → `[4,8,8,9,7,4,3,3,4]` (2..10F) |
| **P1 거리 계승** | `d_i ~ floor` Spearman ρ | 실측 ρ ≈ 0.99 (준단조) |
| **P2 독립성** | `floor ~ horizontal` Spearman ρ ≈ 0 확인 | 실측 ρ ≈ −0.03 — 긴 수평이동이 고층에 몰리는 편향 없음(비교실험 공정성 근거, 보고 권장) |
| **w 민감도** | w ∈ {405, 500, 559, 735} m 에서 층 분포·KPI 대조 | w 축소 시 10F 클립 편중 증가 주의(예: w=405 에서 10F 18%) |
| **강건 변형 대조** | 백분위 앵커 아핀 사상(p1→2F, p99→10F) | 클립 인공물 통제 |
| **귀무모형 대조** | 등빈도(각 층 균등 건수) 배정과 KPI 비교 | 층 prior 선택에 대한 결과 강건성 입증 |
| **앵커 민감도** | centroid vs geometric median, ±500 m | KPI 변화 보고 |
| **재현성** | 층 배정은 데이터만으로 결정론적, 호실은 RNG 명세 고정 | 동일 입력·명세 → 동일 결과 |

## 4. 방법의 성질

- **P1 (거리 계승)** 층은 관측 배달거리의 아핀 이산화 → 수직 차원에 원본 거리의 순위·분포 형상이 보존된다(실측 ρ ≈ 0.99).
- **P2 (입지·층 독립)** 건물 입지(수평 앵커)와 층(수직)이 서로 다른 정보원(중심점 vs 개별 배달거리)을 사용 → 층↔수평거리 독립(실측 ρ ≈ −0.03).
- **P3 (고정성·비교가능성)** 앵커·밴드폭·시드 등 모든 파라미터가 시나리오 불변 → 여러 시나리오를 같은 건물에서 반복 관측하는 설정과 정합하며 시나리오 간 비교가 가능하다.
- **P4 (재현성)** 층·거리분해는 데이터만으로 결정론적, 호실만 RNG 명세 고정 무작위.
- **P5 (일반성)** 층·호실 배정(Step 2–4)은 배달거리만 사용하므로 좌표계·지역과 무관하게 **모든 시나리오 파일에 적용**된다. 지역 종속 요소(앵커, w, c)는 값이 아닌 **추출 절차**로 정의되어 있어 다른 데이터셋에도 동일 절차로 이식된다.

### 5.1 건물 앵커 좌표

수도권(강남 일대) 좌표를 갖는 기준 파일 6개(K50_1/2, K100_1/2, K200_1/2)의 **전체 고객 좌표(DLV_LAT, DLV_LON)를 통합한 산술평균**. 앵커는 수평 이동거리의 기준점으로만 쓰이므로(층 배정 무관), 층별 수요 배분의 일반성에는 영향을 주지 않는다. 다른 지역 데이터셋에 적용할 때는 해당 지역 고객좌표 평균으로 동일하게 재추출한다.

### 5.2 우회계수 c = 1.402

전 주문에 대해 `DIST[i][K+i] / haversine(shop_i, customer_i)` 를 계산한 결과, 파일 크기·지역과 무관하게 평균 1.402, 주문별 표준편차 ≈ 4×10⁻⁴ 의 **상수**로 확인되었다(K50·K100·K200·K1000 파일 실측). 즉 데이터 생성기가 대권거리에 곱한 고정 우회계수이며, 문헌의 실측 우회계수 범위 1.2–1.5 와 부합한다. 층 배정용 거리와 수평 이동거리의 척도 일관성을 위해 Step 6 ①에 동일 값을 적용한다.

### 5.3 밴드폭 w = 500 m

A2(지지집합 아핀 보정)에 따라 `w = range(d)/9` 로 유도한다. 기준 파일 실측:

| 유도 방식 | w |
|---|---|
| K50_1 (max−min)/9 | 478 m |
| K100_1 / K100_2 range/9 | 522 / 508 m |
| K50_2 range/9 | 559 m |
| K200_1 / K200_2 range/9 | 684 / 735 m |
| 통합 (p99−p1)/9 | 559 m |
| 통합 (p95−p5)/9 | 405 m |

유도값은 405–735 m 범위에 분포하며, **500 m 는 이 범위의 중앙 대표값(특히 K50/K100 계열 478–559 m 와 근접)의 반올림**으로 채택한 고정값이다. 유도 방식 간 차이는 Step 7의 w 민감도 프로토콜로 통제한다. 배달거리 스케일이 다른 데이터셋에서는 동일 절차(`range/9`)로 w 를 재유도한다.

### 5.4 건물 사양 파라미터

`configs/baseline_10f.yaml` 의 10층 사무건물 타이폴로지에서 온다: 층고 4.0 m(총 40 m), 층당 바닥면적 ≈ **1,200 m²**(복도 **34 m**, 중복도형), 층당 호실 12개(남 6·북 6, 복도 위치 **[2,7,12,22,27,32] m** — 복도 중점 17 m 거울 대칭, 12~22 m는 EV 서비스 코어), 로비(1F)를 제외한 사무층 2..10F, **승강기 4대**(가속 1.0 m/s², 최고 2.5 m/s — A1 정직성 조항의 층당 한계시간 산출에 사용). 입구 성분 4.0 m 는 빌딩 그래프의 `lobby_entry → floor_1_center` 간선거리다.

> **본 절의 건물 상수는 H0 v2 개정(2026-08-03)과 사무실 재배치(2026-08-04)로 갱신됐다** (구값: 800 m² / 복도 27 m / [3,7,11,15,19,23] / 승강기 2대 → v2 초기 [4,9,14,19,24,29] → 현행 [2,7,12,22,27,32]). 층수(10)와 사무층 범위(2..10F)는 불변이므로 **본 방법론의 매핑 절차 자체는 영향을 받지 않는다** — 층 프로파일은 층수에만 의존하고 복도 기하와 독립이기 때문이다(검증계획서 §0.3). 또한 v2는 **지하 2개층(B1·B2)** 을 신설했으나 그 층들은 사무공간이 없어 **수요 매핑 대상이 아니다**.

## 6. 한계

- **서수적 등가일 뿐 기수적 등가가 아님**: 본 매핑은 노력 순위와 분포 형상을 보존할 뿐, 절대 시간 스케일을 보존하지 않는다(A1 정직성 조항).
- **총거리의 수평 지배**: 수직(층)에 담긴 원본 거리정보(수 m~수십 m)는 수평(수백~수천 m) 대비 작아, `total_travel_m` 은 수평 성분이 지배한다(기준 파일 실측 ≈ 98%). 원본 거리정보는 **층 차원에 보존되나 총 이동거리 총량으로는 전달되지 않는다.**
- **형상 계승은 모형 선택**: "층별 수요 형상 = 관측 거리분포 형상"(A2)은 직접 검정이 불가능한 공리다. 방어는 귀무모형(등빈도) 대조에서 KPI 결론이 뒤집히지 않음을 보이는 방식으로 한다(Step 7).
- **파라미터의 데이터 종속**: c·w·앵커는 본 데이터셋에서 유도된 고정값이며, 다른 데이터셋에는 §5의 절차로 재유도해야 한다.
- **범위 외 사항**: 원본 `DLV_DEADLINE` 의 활용 방식은 본 문서의 범위 밖이며 추후 별도로 정의한다.

## 7. 문헌 포지셔닝

**채택 근거**
- **Trace-driven 입력 모델링**: 가정된 모수분포 대신 관측 경험분포를 시뮬레이션 입력으로 쓰는 표준 원칙 — 본 방법론의 제1 근거.
- **등시선(isochrone)·접근성 문헌**: 층을 "수직 서비스권역의 등노력 밴드"로 해석 — 2D 배달권의 거리밴드와 구조적 대응(엘리베이터를 수직 교통축으로 보는 vertical urbanism 논의와 연결).
- **음식배달 라우팅(MDRP)**: 원본 2D 데이터의 학술적 지위(Reyes et al. 2018; Ulmer et al. 2021 계열)와 실데이터 기반 실험 전통.
- **우회계수 실측 문헌**: Ballou et al. (2002), Boscoe et al. (2012) — c = 1.402 의 타당성 범위.

**검토 후 기각한 대안 (기각 사유 기록)**
- **방사투영(고객→앵커 거리 기반 층 배정)**: 논리적으로는 "고객 속성으로 층 결정"이라 깔끔하나, 식당·고객 위치의 공간 상관 때문에 층↔수평거리에 **인공 의존성(실측 ρ ≈ +0.56)** 이 생겨 비교실험의 교란변수가 됨 → 기각.
- **외부 수직 데이터 기반 주변분포(재실인구·건물대장 등)**: 실측 재실 데이터가 있을 때의 표준(엘리베이터 교통공학: Barney & Al-Sharif; CIBSE Guide D)이나, 본 연구 설정에서는 해당 실측이 존재하지 않아 또 하나의 가정이 될 뿐임 → 주 방법으로 채택하지 않고, 등빈도 귀무모형 대조(Step 7)로 층 prior 강건성만 확인.

**대조 위치**: 재실인구 기반 층 수요는 "실측 재실 데이터가 있을 때의 표준"이며, 본 방법론은 그것이 없는 조건에서 **관측된 수요 분포 자체를 계승**하는 대안으로 위치한다.
